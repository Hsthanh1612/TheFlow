# Luồng người dùng chính
1. Đăng ký → chờ kích hoạt → quản trị gán đơn vị+vai trò → vào app (realtime, không cần tải lại).
2. Tạo việc (loại việc → form sinh từ trường cấu hình → kiểm tra bắt buộc) → người phụ trách nhận thông báo.
3. Làm việc: Chờ làm → Đang làm (checklist, mô tả tự lưu) → Nộp để duyệt → người duyệt Duyệt/Trả lại (bắt buộc ý kiến) → Hoàn thành. Kanban kéo thả đi cùng quy tắc.
4. Quản lý: Chờ duyệt (hàng loạt), Giao công việc (xem trước → một batch), Cảnh báo quá hạn (Tạo lời nhắc/Đổi người/Gia hạn có lý do), Báo cáo (CSV/in).
5. Cấu hình: sửa loại việc/trường/quy trình/vai trò/cây tổ chức; Nhờ AI → dán JSON → diff → áp dụng; khôi phục từ Lịch sử.
Trạng thái: đang tải / rỗng / lỗi (phân loại, thông báo dễ hiểu) / không đủ quyền đều có trong từng màn.
